# New Project: MOBA Game MVP

## 📁 MobaGame/

This repository now includes a complete Unity MOBA game MVP prototype with .NET TCP server backend.

这个仓库现在包含了一个完整的 Unity MOBA 游戏 MVP 原型，以及 .NET TCP 服务器后端。

### Features

✅ Unity 2022.3 LTS MOBA Game Client
✅ .NET 8.0 TCP Server
✅ 5 Hero Classes (Tank/Fighter/Assassin/Mage/Marksman)
✅ 5v5 Three-Lane Map
✅ Complete UI Flow (Login → Lobby → Hero Selection → Battle → Results)
✅ Combat System (Minions, Towers, Skills, Items)
✅ Shop & Economy System
✅ Chat System
✅ Network Infrastructure

### Getting Started

```bash
# Start the server
cd MobaGame/DotNetServer/MobaServer
dotnet run

# Open Unity project
# Unity Hub → Add → MobaGame/UnityClient
# Open with Unity 2022.3 LTS
```

See [QUICKSTART.md](./MobaGame/QUICKSTART.md) for detailed instructions.
